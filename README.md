# Settings-Menu-Godot

Menu de configurações pré-pronto para a Godot Engine. Feito para jogos com escopo pequeno.

## ATENÇÃO

Este projeto foi desenvolvido com o auxílio de Inteligência Artificial Generativa (I.A.G).

Isso significa que o projeto passou pelo seguinte processo:

```text
Escrito (ideia) > Escrito (código) > Analisado (I.A.G) > Analisado (por mim)
```

### Por que estou utilizando I.A. para "fazer o trabalho por mim"?

Não, **eu não estou utilizando a I.A. para fazer todo o trabalho por mim**. Estou utilizando-a principalmente para análise e auxílio no desenvolvimento do código.

Até o momento, criar um sistema completamente do zero não é uma tarefa tão simples para mim. Por isso, utilizo a I.A. como uma espécie de **mentor/auxiliar**, que me ajuda a entender e resolver as partes mais complicadas do projeto.

Então, sim, estou utilizando I.A. para realizar parte do trabalho, mas não todo ele. A maior parte do desenvolvimento, das decisões e da implementação é feita por mim. A I.A. é utilizada principalmente como uma ferramenta de auxílio durante a programação.
